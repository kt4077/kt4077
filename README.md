## 关于我们

> 晨风工作室是一家专注于 **AI 应用落地、SaaS 系统研发与微信生态产品开发** 的技术工作室。

团队深耕 **教育数字化、电商智能化、生活服务轻量化** 场景，坚持实用落地、开源开放、可二次开发、可私有化部署的产品理念，致力于用轻量化技术方案降低行业数字化门槛，为个人开发者、自媒体讲师、教育机构、中小电商商家提供高效、自主可控的工具与解决方案。

我们主打 **全链路产品自研**，从需求设计、功能开发到线上落地、接口开放全程自主把控，所有核心项目均支持 API 对接、功能拓展与个性化定制，适配各类业务迭代与场景延伸需求。

## 代表作品

<details open>
<summary><b>1. 晨风 AI 知识付费系统</b></summary>

<br />

新一代 AI 赋能知识付费闭环系统，告别传统单一卖课模式，打造 **学、练、考、管、裂变、变现** 全闭环私域教学运营体系。

- AI 智能答疑、题库解析、学情复盘、在线考试、电子资料管理
- 多级分佣裂变、积分留存、资讯运营模块，低成本实现用户自传播拓客
- 资金自主结算、无平台抽成，数据可私有化部署，资产永久沉淀
- 深度适配微信小程序与公众号私域流量，配套完整开放 API，支持二次开发

</details>

<details>
<summary><b>2. 晨风电商 Agent 工作台</b></summary>

<br />

面向中小电商商家的 AI 全链路经营工作台，覆盖商品创作、内容生成、店铺运营、客服对接等核心场景。

- AI 生成商品标题、主图、详情文案、短视频脚本，适配多平台发布
- 新品上架与内容制作效率提升数倍，支持批量内容生产
- 覆盖选品、内容创作到售后客服全流程，降低人工运营成本

</details>

<details>
<summary><b>3. 晨风萌爪日记（微信小程序）</b></summary>

<br />

面向养宠用户的轻量化生活服务小程序，专注宠物成长记录与养宠社群交流。

- 宠物照片一键生成成长视频，搭建专属私人宠物相册
- 萌宠广场支持晒宠分享、互动问答、养宠经验交流
- 用数字化方式珍藏人与宠物的美好回忆

</details>

<details>
<summary><b>4. go_backend_frame（开源 · 全栈基础框架）</b></summary>

<br />

一套开箱可用的后台管理系统全栈脚手架，包含 Go 后端 `server_api` 与 Vue 3 管理前端 `admin_client`，可直接作为 SaaS 与中后台项目的开发底座。

- 后端：管理端 `:8001` 与用户端 `:8002` 双端独立启动、独立部署
- 鉴权：JWT + Redis 会话，支持主动退出、改密失效、管理员踢下线
- 权限：菜单 / 角色 / 部门树形结构，接口级 RBAC 鉴权
- 前端：后端菜单驱动的动态路由，页面权限 + 按钮权限，明暗主题、标签页、水印
- 存储：本地、阿里云 OSS、腾讯云 COS、七牛云 Kodo、MinIO 五种渠道
- 工程化：启动自检、优雅停机、OpenAPI 文档、中英文文档与代码规范 Skill

</details>
